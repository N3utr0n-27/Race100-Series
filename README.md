# RACE100 2027 – Season Planner (Version 2)

Responsive, statische Rennkalender-Webseite für die RACE100 GT3 Series 2027.

## Inhalt
- Acht Rennabende und Strecken (Februar bis November 2027)
- Nächstes Rennen mit Countdown (Schweizer Zeit)
- Vereinfachte SVG-Streckensilhouetten pro Rennen
- Drei dezente Pace-Richtwerte pro Strecke für Assetto Corsa Original / GT3
- Aufklappbare Erklärung zu den Richtwerten
- Mobile-First-Darstellung und dunkles, neutrales Design mit Akzentfarbe `#EF2525`

**Hinweis:** Keine Kalenderexportfunktion, kein Login und keine Datenspeicherung. Rennabende sind 18:00–22:00 Uhr Schweizer Zeit. Die Rundezeit-Richtwerte sind indikativ und variieren je nach Fahrzeug, Strecke, Mod und Bedingungen.

## GitHub Pages
1. Neues GitHub-Repository erstellen.
2. `index.html` im Root des Repositorys ablegen (und optional diese `README.md`).
3. Unter **Settings → Pages → Build and deployment**: **Deploy from a branch**, Branch **main**, Ordner **/(root)** wählen.
4. Nach dem Deployment ist die Seite über die von GitHub angezeigte Pages-URL abrufbar.

Keine Abhängigkeiten oder Build-Schritte erforderlich.
